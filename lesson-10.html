Masked Self-Attention: How LLMs Learn Without Seeing the Future

Chapter 2 · Causal Masking · Parallel Training · The -inf Trick

The Lesson

Every decoder-only LLM — GPT-3, Llama, Mistral, Claude — relies on a single architectural trick to learn: masked self-attention. Without it, the model would cheat during training by peeking at future tokens, and its predictions would collapse into meaningless noise.

The problem is this: Transformer layers compute attention in parallel across all positions in a sequence. That parallelism is what makes Transformers fast. But for language modeling, each token should only attend to tokens that come before it — never after. If position 3 can see position 5, the model learns to "copy the answer" instead of actually predicting it.

Masked self-attention solves this by adding a causal mask — an upper-triangular matrix of negative infinities — to the attention scores before the softmax. When you add -inf to a score and pass it through softmax, that position gets a weight of exactly 0. The model literally cannot attend to future tokens.

The brilliance is in the simplicity. Instead of training the model step-by-step (which would be serial and slow), you feed the entire sequence into the model at once and use the mask to enforce causality. Every position in the batch predicts its next token simultaneously — parallel training with causal guarantees.

Building the Mask

The mask is an upper-triangular matrix filled with -inf. PyTorch makes this trivial:

import torch
import torch.nn.functional as F

seq_len = 5

# Step 1: Fill with -inf
mask = torch.full((1, 1, seq_len, seq_len), float("-inf"))

# Step 2: Keep only the upper triangle (future positions)
mask = torch.triu(mask, diagonal=1)

print(mask[0, 0])
# tensor([[-0., -inf, -inf, -inf, -inf],
#          [-0., -0., -inf, -inf, -inf],
#          [-0., -0., -0., -inf, -inf],
#          [-0., -0., -0., -0., -inf],
#          [-0., -0., -0., -0., -0.]])

Note the batch and head dimensions (1, 1, ...) — these broadcast across all batches and all attention heads automatically.

Applying the Mask to Attention Scores

The mask gets added to the raw attention scores before softmax. Here's the critical step:

# Raw attention scores: (batch, heads, seq_len, seq_len)
scores = torch.matmul(Q, K.transpose(-2, -1)) / math.sqrt(d_k)

# Add the causal mask — broadcasts across batch and heads
scores = scores + mask[:, :, :seq_len, :seq_len]

# Softmax: -inf positions become exactly 0
attention_weights = F.softmax(scores.float(), dim=-1)

# Weighted sum of values
output = torch.matmul(attention_weights, V)

Why addition instead of multiplication? Because softmax is applied after the mask. Adding -inf pushes those scores to the bottom of the softmax distribution, where they become 0. If you multiplied by 0 first, you'd get NaN after softmax (since softmax of all-zeros is uniform, not zero).

Why -inf and Not Just 0?

A common question: why not just set masked scores to 0 instead of -inf?

softmax([2, 0, 0, 0]) = [0.64, 0.12, 0.12, 0.12]
softmax([2, -inf, -inf, -inf]) = [1.0, 0.0, 0.0, 0.0]

Setting masked scores to 0 gives them some attention weight (about 12% each in this example). The model would still "see" future tokens, just less strongly. Only -inf guarantees zero attention to future positions.

Key Takeaway

Masked self-attention enables parallel training of causal language models. Instead of generating tokens one-by-one (slow, serial), the entire sequence is processed at once with a causal mask enforcing that each position only attends to past tokens. The -inf trick in the attention scores guarantees zero leakage of future information.

Why It Matters

Training speed. Without causal masking, training a decoder LLM would require sequential token-by-token generation — exactly the RNN bottleneck that Transformers were designed to eliminate. Masked self-attention gives you the best of both worlds: causal behavior during training with full parallelism.

Training-serving symmetry. During inference, LLMs generate tokens one at a time naturally — each new token only sees previous ones. Masked self-attention ensures the model learns the same causal dependency during training. If it could peek ahead during training, it would learn shortcuts that don't exist at inference time, causing a severe train-test mismatch.

The foundation of every chatbot. Every time you chat with an LLM, masked self-attention is what ensures it generates its response token by token, building on what it has already said rather than jumping ahead. Understanding this mechanism is essential for debugging generation issues, implementing custom attention patterns (like sliding window or sparse attention), and building efficient inference engines.
